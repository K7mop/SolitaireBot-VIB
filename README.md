# مساعد السوليتير 0.8.10 — سرعة متكيفة وتحقق بصري

هذا تحديث **للمشروع الأصلي نفسه**، مبني على مصدر 0.8.9. معرّف التطبيق `com.retq.solitairebot`؛ الإصدار الداخلي `810`. الاستخدام المقصود لعبة سوليتير تجريبية بأموال وهمية. تحتوي الحزمة مشروع Android Studio الكامل لبناء APK.

## سرعة التشغيل

أُزيلت فترات انتظار متراكبة، وخُفّض العمل المتكرر في معالجة الصورة. تستمر الحلقة: صورة جديدة ← قراءة الأوراق ← ترتيب النقلات ← إرسال حركة واحدة ← التحقق من نتيجتها ← القرار التالي.

| المرحلة | 0.8.9 | 0.8.10 |
|---|---:|---:|
| فترة الالتقاط النشط الدنيا في الخدمة | 333 ms | 33 ms، عند طلب القارئ فقط |
| فترة تحليل الصور النشطة الدنيا | 210 ms | 50 ms |
| مدة السحب الابتدائية | 340 ms | 145 ms |
| مدة النقرة الابتدائية | 75 ms | 42 ms |
| انتظار إضافي بعد نجاح الحركة بصرياً | 390 ms | أُزيل |
| نتائج التحليل المنتظرة للمعالجة | غير محدودة صراحةً | نتيجة واحدة |

هذه إعدادات البرنامج وليست وعداً بمعدل إطارات فعلي على الهاتف. يتجاوز المساعد تحويل الصورة عندما تكون إيماءة قيد الإرسال أو نتيجة تحليل سابقة معلقة. تبقى اللقطة اليدوية الأولى كاملة الدقة.

بعد انتهاء الإيماءة توجد مهلة أولية 55 ms، ثم يلزم **إطاران جديدان** يفصل بينهما 40 ms على الأقل، يثبتان الانتقال المتوقع للأوراق. تأكيد أندرويد انتهاء اللمس وحده لا يكفي. تُطوَّل الإيماءة تدريجياً عند الإخفاق إلى حد 320 ms للسحب و82 ms للنقرة، وتعود تدريجياً بعد نجاحات مؤكدة. لا تتكرر النقرة الفاشلة على الحالة نفسها.

## المخزون ومؤشر التحميل

يعامل القارئ ظهر الأوراق المتاحة، وسهم إعادة المخزون الأخضر، ومؤشر تحميل اللعبة الذهبي المتحرك، كحالات مختلفة. أثناء التحميل يستمر الرصد وتُمنع اللمسات الجديدة. بعد زواله تلزم قراءة مستقرة جديدة. يستند التعرف إلى الأمثلة المتاحة، وقد يحتاج اختلاف الثيم أو الأبعاد إلى تشخيص إضافي.

لا تُحتسب إعادة المخزون ناجحة إلا بعد رصد انتقاله إلى أوراق متاحة وتغير كومة السحب وفق الانتقال المتوقع. كلفة إعادة المخزون المستخدمة في التقييم **15 نقطة**، حسب وصف المستخدم. تمنع الذاكرة تكرار دورة بلا تقدم، وتسمح بإعادة التقييم بعد حركة مؤكدة تفتح فرصة جديدة. أُصلح الحظر الذي كان يبقى مفعلاً بعد تغيّر الفرص.

## قرارات اللعب

يبقى البحث المحدود في الحركات المعروفة، والبحث عبر عدة مسارات، وأولوية كشف الأوراق، والرفع الآمن للأساسات، ومنع تكرار الحالات. تُختصر عمليات البحث الزائدة عند وجود خيار واحد فقط. أُصلحت حالة كان فيها إرجاع ورقة من الأساس يُستبعد رغم أنه يتيح نقل سلسلة وكشف ورقة مقلوبة معروفة.

يمكن إعطاء أولوية للكشف عندما يظهر دليل بصري على ظهر ورقة مباشرة خلف السلسلة المقروءة، حتى إن كان عدد الأوراق المخفية مجهولاً. لا يتحول العدد إلى رقم تخميني ولا تُملأ هويات الأوراق المخفية في البحث المستقبلي.

تحسنت قراءة رسوم الأوراق من الصور المرفقة. عندما تكون الورقة كاملة الظهور ويكون رقمها العلوي ملتبساً، يمكن لرقمها السفلي الأيمن الواضح تأكيد أفضل احتمال علوي مطابق. يبقى هذا المسار مغلقاً للأوراق المتراكبة، ولا يخفض حد التشابه أو يدوّر الرقم لتخمين 6 أو 9. نجاح الصور المستخدمة في التطوير لا يضمن قراءة كل ثيم أو لقطة مموهة؛ تفاصيل الامتناع عن القراءة موجودة في تقرير الاختبارات.

الأوراق المخفية لا تُختلق هوياتها. لا يوجد وعد بحل كل توزيع أو تحقيق 14,000 نقطة؛ ذلك يحتاج اختبار جولات فعلية ومعرفة مكافأة الإنهاء ونظام نقاط اللعبة.

## البناء في Android Studio

1. فك ضغط ZIP في مجلد جديد على اللابتوب.
2. افتح مجلد `SolitaireBot-Ready` الذي يحتوي `settings.gradle.kts`.
3. انتظر اكتمال Gradle Sync، ثم ابنِ APK بالطريقة المعتادة.
4. ثبّت APK على الهاتف وتأكد أن عنوان المساعد يعرض **0.8.10**.

لم تتغير إصدارات أدوات البناء: Android Gradle Plugin 8.10.1، Kotlin 2.2.21، Gradle 8.11.1، Java 17، وAndroid SDK 35. ملفات Gradle هي مرجع الإعدادات. الحد الأدنى للنظام Android 8 / API 26.

## التشغيل بعد التثبيت

1. افتح المساعد وتأكد من تفعيل خدمته في **إمكانية الوصول** وإذن **الظهور فوق التطبيقات**.
2. اضغط **«تفعيل التحريك التلقائي بعد اللقطة الأولى»** إذا لم يكن مفعلاً.
3. ابدأ مشاركة **الشاشة كاملة**، ثم انتقل إلى اللعبة التجريبية.
4. ابدأ الجولة وأظهر الأوراق الموزعة. من النافذة العائمة اضغط **«لقطة وبدء تلقائي»** مرة واحدة.
5. عند نجاح التعرف تستمر القراءة والسحب والنقل والقلب وإعادة المخزون المبررة تلقائياً. الزر العائم الأحمر يوقف المساعد.
6. بعد الجولة افتح المساعد واضغط **«تصدير تقرير الجولة»**. يحتوي أزمنة التنفيذ والأخطاء، ويُشارك عندما تختار أنت وجهته.

لا يتولى المساعد بدء الجولة أو الضغط على زر وضع الرهان. يبدأ عداده الاحتياطي عند التشغيل التلقائي، أو يستخدم توقيت بداية الجولة المحدد اختيارياً. قراءة عداد اللعبة المستقرة توجه الاستراتيجية. ابدأ التشغيل عند بداية الجولة للاستفادة من الوقت.

عند ظهور انتظار تحميل اللعبة، اترك المؤشر يزول. عند وجود مناطق غير معروفة أو غياب حركة مؤكدة، يستمر الرصد حتى تتغير اللوحة أو تنتهي المهلة. لا تُرسل نقرات بلا دليل على مواضع الأوراق.
