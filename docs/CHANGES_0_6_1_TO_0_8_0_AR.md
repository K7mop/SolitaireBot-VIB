# ما أضيف إلى الحزمة الأولية 0.6.1؟

الحزمة الأصلية احتوت ملفات معايرة أولية لخدمة التقاط الشاشة، لكنها لم تتضمن مشروع Android Gradle متكاملًا أو محركًا للحالة والنقلات أو واجهة تعليم واعتماد أو تنفيذًا مراقبًا للمس.

أضيفت الآن وحدتا `app` و`core` وملفات البناء، وواجهة عربية، وحفظ لقطة ومعايرة 13 منطقة، وتصنيف صور بطاقات بعد تعليمها من المستخدم، ونموذج Klondike Draw-3، وتوليد النقلات واقتراحها، ومؤقت خمس دقائق، وخدمة اللمس لنقلة واحدة. كما تم إصلاح تسلسل طلب MediaProjection وإغلاق الإطارات، وإضافة آلية قراءة مزدوجة وتحقق بصري بعد تنفيذ الحركة وعدم تكرارها تلقائيًا، واعتماد جديد لمعايرة كل جلسة.

ما يزال بناء APK واختبار Android الحقيقي ودقة قراءة جميع بطاقات لعبة المستخدم وتحقيق نتائج فعلية في الجولات **غير مُثبت**. هذا الإصدار إكمال تأسيسي قابل للبناء والفحص في Android Studio، وليس إصدارًا إنتاجيًا مختبرًا بالكامل.
